Create your first .txt ORB — no plugin needed

  1. Explore a topic. Copy the ORB prompt into your AI chat, then type /orb your topic. Follow questions and check sources.
  2. Create the file. In ORB Share, copy the authoring brief into that same chat. Ask for your exploration as an ORB File 1 named your-topic.orb.txt. No HTML or plugin installation is needed.
  3. Preview and save. Open the AI’s file in ORB Share. If it gives you text instead, copy the JSON inside its code block, choose Paste text → Check & open, then Save ORB file. If there are errors, copy them back to your AI and ask it to fix the file.
  4. Submit for review. Choose Prepare submission, check your title and public creator credit, then continue to GitHub. Sign in or create a GitHub account, attach the saved .orb.txt to the issue description, and submit. Keep the issue link as your receipt. Previewing does not upload the file or publish it.

Plugin 1.3.0 includes the new orbshare exporter. The old orbengine is retained only for explicit legacy maintenance; its terrain files need conversion before ORB Share can open them.

Crea tu primer ORB .txt — sin instalar un plugin

  1. Copia el prompt ORB en tu chat de IA y explora un tema.
  2. Copia las instrucciones de creación de ORB Share en ese mismo chat. Pide un archivo tema.orb.txt en formato ORB File 1.
  3. Abre el archivo en ORB Share, o pega el JSON con Paste text → Check & open. Revisa el contenido y pulsa Save ORB file.
  4. Pulsa Prepare submission, revisa tu crédito público y los permisos, inicia sesión en GitHub y adjunta el archivo guardado a la descripción antes de enviar. La vista previa no publica ni sube el archivo.

El prompt descargado contiene instrucciones; el archivo ORB terminado contiene tu exploración. El motor antiguo se conserva solo para mantenimiento de archivos heredados.

What the orb is

Give the orb a topic and it becomes a place you navigate. Six directions, one meaning each:

▲ up
broader ◀ left
around● dwellright ▶
around ▼ down
deeper

Up goes broader, down goes deeper, left and right move around the ring of neighboring ideas, and forward / backward travel along consequence — what follows from here, what led to here. Hand it a task instead of a topic ("write the launch email") and the same directions become moves on the work itself.

Rhythm mode drags a timeline across years, decades, or centuries and reads a topic like sheet music — recurring beats, tempo, motifs, rests, syncopation, overlapping cycles. There's an anchor-or-drift reading, a triangulator, chained flights ("two right, one forward"), and a creative mode for eccentric destinations.

Qué es el orbe

Dale un tema al orbe y se convierte en un lugar que navegas. Seis direcciones, un significado cada una:

▲ arriba
más amplio ◀ izquierda
alrededor● habitarderecha ▶
alrededor ▼ abajo
más profundo

Arriba amplía, abajo profundiza, izquierda y derecha recorren el anillo de ideas vecinas, y adelante / atrás viajan por la consecuencia — qué sigue de aquí, qué llevó hasta aquí. Entrégale una tarea en vez de un tema ("escribe el correo de lanzamiento") y las mismas direcciones se vuelven movimientos sobre el trabajo mismo.

El modo ritmo arrastra una línea de tiempo por años, décadas o siglos y lee un tema como una partitura — pulsos recurrentes, tempo, motivos, silencios, síncopa, ciclos superpuestos. Hay una lectura de ancla-o-deriva, un triangulador, vuelos encadenados ("dos a la derecha, uno adelante") y un modo creativo para destinos excéntricos.

Three current skills · plugin 1.3.0

/orb

The live session. Opens in the chat; you click directions and the orb flies. Verb mode drives real work-products move by move. Park it, resume it, change granularity mid-flight.

/orbprint

Prints an orb as ONE self-contained HTML file — a slowly rotating globe of the subject, browsed by clicking points, a path line drawn between everywhere you've been. Keep it, reopen it, share it.

/orbshare

Create an ORB File 1 .orb.txt from your readings, sources and connections. Open it in the shared ORB Share reader. No HTML authoring required.

Tres habilidades actuales · plugin 1.3.0

/orb

La sesión en vivo. Se abre en el chat; haces clic en direcciones y el orbe vuela. El modo verbo dirige trabajos reales movimiento a movimiento. Apárcalo, retómalo, cambia la granularidad en pleno vuelo.

/orbprint

Imprime un orbe como UN solo archivo HTML autocontenido — un globo del tema que rota lentamente, navegado con clics, con una línea de ruta entre todos los lugares visitados. Guárdalo, reábrelo, compártelo.

/orbshare

Crea un .orb.txt de ORB File 1 con lecturas, fuentes y conexiones. Ábrelo en ORB Share; no necesitas crear HTML.

Optional plugin installation

The downloads above contain plugin 1.3.0, including ORB Share. The .plugin and .zip downloads contain the same files. No installation is required for the portable prompt and ORB Share workflow.

For Claude Code, extract the archive to a folder and load it with claude --plugin-dir /path/to/orb2. Official plugin instructions ↗. Other hosts may provide a plugin import interface; use the options actually available in your app.

What the orb is

Give the orb a topic and it becomes a place you navigate. Six directions, one meaning each:

▲ up
broader ◀ left
around● dwellright ▶
around ▼ down
deeper

Up goes broader, down goes deeper, left and right move around the ring of neighboring ideas, and forward / backward travel along consequence — what follows from here, what led to here. Hand it a task instead of a topic ("write the launch email") and the same directions become moves on the work itself.

Rhythm mode drags a timeline across years, decades, or centuries and reads a topic like sheet music — recurring beats, tempo, motifs, rests, syncopation, overlapping cycles. There's an anchor-or-drift reading, a triangulator, chained flights ("two right, one forward"), and a creative mode for eccentric destinations.

Qué es el orbe

Dale un tema al orbe y se convierte en un lugar que navegas. Seis direcciones, un significado cada una:

▲ arriba
más amplio ◀ izquierda
alrededor● habitarderecha ▶
alrededor ▼ abajo
más profundo

Arriba amplía, abajo profundiza, izquierda y derecha recorren el anillo de ideas vecinas, y adelante / atrás viajan por la consecuencia — qué sigue de aquí, qué llevó hasta aquí. Entrégale una tarea en vez de un tema ("escribe el correo de lanzamiento") y las mismas direcciones se vuelven movimientos sobre el trabajo mismo.

El modo ritmo arrastra una línea de tiempo por años, décadas o siglos y lee un tema como una partitura — pulsos recurrentes, tempo, motivos, silencios, síncopa, ciclos superpuestos. Hay una lectura de ancla-o-deriva, un triangulador, vuelos encadenados ("dos a la derecha, uno adelante") y un modo creativo para destinos excéntricos.

Three skills in the box

/orb

The live session. Opens in the chat; you click directions and the orb flies. Verb mode drives real work-products move by move. Park it, resume it, change granularity mid-flight.

/orbprint

Prints an orb as ONE self-contained HTML file — a slowly rotating globe of the subject, browsed by clicking points, a path line drawn between everywhere you've been. Keep it, reopen it, share it.

/orbengine

The author's bench. Builds .orb.txt terrain files that Orb Studio renders — bands, positions, ring order, meridians, the anchor, honest edges. Placement is computed, never eyeballed.

Tres habilidades en la caja

/orb

La sesión en vivo. Se abre en el chat; haces clic en direcciones y el orbe vuela. El modo verbo dirige trabajos reales movimiento a movimiento. Apárcalo, retómalo, cambia la granularidad en pleno vuelo.

/orbprint

Imprime un orbe como UN solo archivo HTML autocontenido — un globo del tema que rota lentamente, navegado con clics, con una línea de ruta entre todos los lugares visitados. Guárdalo, reábrelo, compártelo.

/orbengine

El banco del autor. Construye archivos de terreno .orb.txt que Orb Studio renderiza — bandas, posiciones, orden del anillo, meridianos, el ancla, bordes honestos. La colocación se calcula, nunca se hace a ojo.

Install the plugin in Claude

The download is a standard Claude plugin — a folder with a .claude-plugin/plugin.json manifest and a skills/ directory. Two ways in:

Cowork / Claude desktop app

  1. Download orb2.plugin with the button above (or grab the plugin-files\orb2 folder from this same directory).
  2. In a Cowork chat, attach or drag in the .plugin file and say "install this plugin." Claude walks it in.
  3. Alternatively, ask Claude: "install the plugin from the folder C:\Users\<you>\Desktop\Orb Plugin\plugin-files\orb2".
  4. Verify: ask "what plugins do I have?" — orb2 should be listed. Then just type /orb.

Claude Code (terminal)

  1. Unzip (or use the ready plugin-files\orb2 folder).
  2. Add the folder that CONTAINS the plugin as a marketplace, then install:

    claude plugin marketplace add "C:\Users\<you>\Desktop\Orb Plugin\plugin-files"
    claude plugin install orb2

  3. Or inside a session: /plugin marketplace add <that folder> → /plugin install orb2.
  4. Restart the session; /orb appears in the skill list.

Full step-by-step with troubleshooting lives in INSTALL_INSTRUCTIONS.md beside this page.

Instalar el plugin en Claude

La descarga es un plugin estándar de Claude — una carpeta con el manifiesto .claude-plugin/plugin.json y un directorio skills/. Dos caminos:

Cowork / aplicación de escritorio de Claude

  1. Descarga orb2.plugin con el botón de arriba (o toma la carpeta plugin-files\orb2 de este mismo directorio).
  2. En un chat de Cowork, adjunta o arrastra el archivo .plugin y di: "instala este plugin." Claude lo instala.
  3. O pídele a Claude: "instala el plugin de la carpeta C:\Users\<tú>\Desktop\Orb Plugin\plugin-files\orb2".
  4. Verifica: pregunta "¿qué plugins tengo?" — orb2 debe aparecer. Luego escribe /orb.

Claude Code (terminal)

  1. Descomprime (o usa la carpeta lista plugin-files\orb2).
  2. Agrega la carpeta que CONTIENE el plugin como marketplace, luego instala:

    claude plugin marketplace add "C:\Users\<tú>\Desktop\Orb Plugin\plugin-files"
    claude plugin install orb2

  3. O dentro de una sesión: /plugin marketplace add <esa carpeta> → /plugin install orb2.
  4. Reinicia la sesión; /orb aparece en la lista de habilidades.
